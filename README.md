# Ros Morris — Artist Portfolio

A responsive single-page portfolio website for Ros Morris, an artist based in the Chilterns.

## Preview locally

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Files

- `index.html` — page content and artwork details
- `styles.css` — responsive editorial design
- `script.js` — mobile navigation, subtle reveal effects, and artwork lightbox
- `assets/art/` — supplied artwork photographs

## Before publishing

Replace the temporary note in the **Enquiries** section with Ros’s preferred public contact method. No email address or social-media profile was invented or published.

Artwork titles are editorial suggestions based on the supplied images and can be changed directly in `index.html`.
